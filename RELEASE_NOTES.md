# COD: MW4 Mac Compatibility 0.1

First public release with startup, performance, shader compatibility, audio and GPU timing improvements, plus automatic connectivity and cache preparation.

Copy the two program files into `sp26` and launch `MW4-Compatibility.exe` through CrossOver. See the README for the recommended setup and tested configuration.

The game is playable and has been largely stable in our tested sessions. Development is at an early stage and further improvements are planned.
